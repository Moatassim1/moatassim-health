# Moatassim Health for iPhone

Home-screen web app that goes with the Moatassim Health PC app. Scan barcodes,
log food for Moatassim or Waifu, add weight and compare both of you side by side.
Data syncs with the PC app through your own Supabase project.

Open the GitHub Pages address in Safari on iPhone, sign in, then Share > Add to Home Screen.

Barcode scanning uses [html5-qrcode](https://github.com/mebjas/html5-qrcode) (Apache 2.0, see vendor/).
